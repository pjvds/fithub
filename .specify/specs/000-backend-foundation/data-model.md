# Data Model: 000-backend-foundation

> Generated by speckit-plan Phase 1 — formal entity model for the FitHub backend.

---

## Storage Overview

| Store | Technology | Purpose |
|---|---|---|
| Primary DB | Cloudflare D1 (SQLite) | Relational data — users, connections, activities, events |
| Blob Store | Cloudflare R2 | FIT/TCX files, raw platform API payloads |
| Per-User State | Durable Objects | Sync coordination — cursors, locks, in-flight jobs |
| Cache | Cloudflare KV | Hot activity feeds, auth issuer keys |

---

## D1 Entities

### users

The root identity entity. Created on first authentication.

| Column | Type | Constraints | Notes |
|---|---|---|---|
| `id` | TEXT | PK | UUID v4 |
| `email` | TEXT | UNIQUE, nullable | Populated by auth; nullable for Apple privacy relay |
| `created_at` | INTEGER | NOT NULL | Epoch seconds |
| `updated_at` | INTEGER | NOT NULL | Epoch seconds |

**Relationships:** 1:N → connections, activities, push_devices

---

### connections

One per user per platform. Stores encrypted OAuth tokens.

| Column | Type | Constraints | Notes |
|---|---|---|---|
| `id` | TEXT | PK | UUID v4 |
| `user_id` | TEXT | FK → users, NOT NULL | CASCADE on delete |
| `platform` | TEXT | NOT NULL | `'zwift'` \| `'strava'` \| `'apple_health'` |
| `status` | TEXT | NOT NULL | `'active'` \| `'requires_reauth'` \| `'disconnected'` |
| `encrypted_tokens` | TEXT | nullable | AES-256-GCM: `v1:iv:ciphertext:tag` (base64); null for apple_health |
| `token_expires_at` | INTEGER | nullable | Epoch seconds |
| `platform_user_id` | TEXT | nullable | E.g., Zwift user ID |
| `scopes` | TEXT | nullable | Comma-separated |
| `connected_at` | INTEGER | NOT NULL | Epoch seconds |
| `last_synced_at` | INTEGER | nullable | Epoch seconds |
| `last_error` | TEXT | nullable | Last sync error message |
| `created_at` | INTEGER | NOT NULL | Epoch seconds |
| `updated_at` | INTEGER | NOT NULL | Epoch seconds |

**Constraints:** UNIQUE(user_id, platform)
**Indexes:** `idx_connections_status(status, platform)`
**State Transitions:** `active` → `requires_reauth` (token refresh failed) → `active` (re-authenticated) | `disconnected` (user revoked)

### activity_sources

Lossless raw payloads from each platform. Many per activity (one per source platform that reported it).

| Column | Type | Constraints | Notes |
|---|---|---|---|
| `id` | TEXT | PK | UUID v4 |
| `activity_id` | TEXT | FK → activities, NOT NULL | CASCADE on delete |
| `source` | TEXT | NOT NULL | Platform name |
| `source_activity_id` | TEXT | NOT NULL | Platform's native ID |
| `raw_payload_path` | TEXT | NOT NULL | R2 path to raw platform payload |

**Constraints:** UNIQUE(source, source_activity_id)
**Indexes:** `idx_activity_sources_activity(activity_id)`

### dedup_pending

| Column | Type | Constraints | Notes |
|---|---|---|---|
| `id` | TEXT | PK | UUID v4 |
| `user_id` | TEXT | NOT NULL | |
| `candidate_activity_id` | TEXT | NOT NULL | New activity awaiting decision |

| `user_id` | TEXT | nullable | |

### outbox_events (AD-5)

Transactional outbox. Domain events staged atomically with state writes via `db.batch()`.

| Column | Type | Constraints | Notes |
|---|---|---|---|
| `id` | TEXT | PK | UUID v4 — becomes CloudEvents `id` |
| `aggregate_type` | TEXT | NOT NULL | `'activity'` \| `'connection'` \| `'sync_job'` \| `'health_upload'` \| `'token'` |
| `aggregate_id` | TEXT | NOT NULL | ID of the entity that changed |
| `event_type` | TEXT | NOT NULL | CloudEvents `type`, e.g. `'activity.created'` |
| `payload` | TEXT | NOT NULL | JSON ≤4 KB; CloudEvents envelope + domain `data` |
| `created_at` | INTEGER | NOT NULL | Epoch ms |
| `processed_at` | INTEGER | nullable | Epoch ms; set by outbox relay after enqueue; NULL = pending |

**Indexes:** `idx_outbox_pending(processed_at) WHERE processed_at IS NULL` (partial index)
**Retention:** Rows marked `processed_at` but never deleted (audit trail). Automated sweep deferred to post-MVP.

---

### processed_events (AD-5)

Consumer-side idempotency. Bounded-window dedup with 24h cleanup.

| Column | Type | Constraints | Notes |
|---|---|---|---|
| `consumer_id` | TEXT | PK (composite) | E.g. `'dedup-engine'`, `'push-notifier'` |
| `event_id` | TEXT | PK (composite) | CloudEvents `id` (= outbox_events.id) |
| `processed_at` | INTEGER | NOT NULL | Epoch ms |

**Indexes:** `idx_processed_events_cleanup(processed_at)`
**Safety invariant:** Cleanup window (24h) MUST > Cloudflare Queues max retry window (12h).

## Durable Object State

### UserSyncCoordinator (1 per user)

Persisted via Durable Object storage API (key-value under the DO instance).

```typescript
interface SyncCoordinatorState {
  userId: string;
  connections: {
    [platform: string]: {
      cursor: string | null;          // last successfully fetched cursor/page token
      lastSyncedAt: number | null;    // epoch seconds
      inFlightJobId: string | null;   // null when no job running
      consecutiveFailures: number;    // reset on success; drives backoff
    }
  };
  schemaVersion: number;              // for state migration
}
```

**Accessed by:** `worker` Worker (sync jobs), `scheduler` Worker (job creation), `api` Worker (status queries)
**Concurrency:** Single-threaded per DO instance — natural per-user serialization.

## R2 Blob Store

**Bucket:** `blob-store` (SST resource-linked)

**Path convention:**
```
users/<user_id>/activities/<activity_id>/<artifact>
```

**Artifact types:**
| Artifact | Example Path | Content |
|---|---|---|
| FIT file | `users/abc/activities/xyz/activity.fit` | Binary FIT data from Zwift |
| TCX file | `users/abc/activities/xyz/activity.tcx` | TCX export |
| Raw Strava JSON | `users/abc/activities/xyz/raw_strava.json` | Full Strava API response |
| Raw Zwift JSON | `users/abc/activities/xyz/raw_zwift.json` | Full Zwift API response |

**Rules:**
- Events reference blobs by **path only** — never URLs, bucket names, or provider URIs
- SST `Resource.Bucket.get(path)` enforces this convention
- Raw payloads preserved losslessly for future re-processing
